## ✨ Features

- **Procedural 3D Ocean Simulation**: High-performance animated wave shaders using Three.js and React Three Fiber.
- **Cinematic Scroll Animations**: Smooth multi-scene GSAP ScrollTrigger canvas sequences highlighting vessel engineering and cruise experiences.
- **Interactive Bento Showcase**: Hover-reactive 3D perspective cards featuring fine dining, craft cocktails, pool decks, and nightlife.
- **Seamless Infinite Marquee**: Smooth gallery carousel showcasing ship decks, lounges, and suites.
- **Full Responsive Design**: Optimized layout across mobile, tablet, and ultra-wide displays.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 App Router (Static Export)
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: GSAP, ScrollTrigger, Framer Motion
- **Smooth Scroll**: Lenis
- **Styling**: Tailwind CSS v4

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/cyber-atharv/navis-luxury-cruises.git

# Navigate into project directory
cd navis-luxury-cruises

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
